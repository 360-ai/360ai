# 360ai Hauptordner

## Ablage

Bevor du hier eine Datei oder einen Ordner anlegst, lies `00_ORDNERSTRUKTUR.md` und ordne das Thema dort ein.
Lege nichts in den gerade offenen Unterordner, nur weil er offen ist. Neue Themen (z. B. eine Branche, ein Kunde,
ein Prospekt) bekommen ihren Platz nach der Tabelle dort. Wenn nichts passt, frag Denis, statt einen neuen
Hauptordner anzulegen.
